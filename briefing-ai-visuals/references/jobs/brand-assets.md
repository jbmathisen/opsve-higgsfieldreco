# Job: brand assets (logo or mark, icon set, illustrations, OG image, favicon)

The user's own assets always win. Generation fills gaps only: never regenerate a replacement for a logo, font or photo the user already has. If their imagery clashes with a new direction, offer a re-grade of their images, not generated substitutes.

## Ready check

- [ ] New identity, extension of an existing one, or refresh? Decide from what the user says, not from whether files are attached
- [ ] Existing logo, palette, typefaces, imagery (read them from the site or files)
- [ ] What the brand stands for in one line, and the core metaphor or object
- [ ] Which assets are needed: mark, wordmark, icon set (how many, for what), illustrations, OG image (1200x630), favicon set, social templates
- [ ] Where each is used and at what smallest size (a favicon at 16 px, an icon at 24 px)
- [ ] Vector or raster: logos and icons should end as editable SVG
- [ ] Rights: no lookalike of another brand's mark, no protected characters

## Think

1. **A mark is an argument,** not decoration: what does it represent, how does it scale from a favicon to a sign, why is it ownable.
2. **Icons:** a real library (one stroke weight, one corner language) for dense UI; a generated set only for a few large brand icons; never both in one area. A generated set is made as one batch so the style holds: a grid of 6 to 12 glyphs in one stroke style and palette on a flat ground, then sliced, or each with a transparent background.
3. **Illustrations:** draw the subject's own things (its product, place, tools, documents), in one graphic language for the whole site, with three levels of detail (big shapes, describing shapes, small details that reward a second look). Not gradient blobs, isometric clip art or generic line people.
4. **OG image:** composed for 1200x630 in the brand language, not a crop of the hero; one per major page if titles differ. The title is set as text in the template where possible.
5. **Favicon:** from a high-resolution source of the real mark; if the mark turns to noise at 16 px, use a simplified glyph for small sizes.

## Make

1. Concept board first for a new identity (palette, mark directions, type, two applications), one board, cheap.
2. Mark in a vector-capable model, then clean up as SVG. Check it at 16, 32 and 512 px and in one color.
3. Icon set as one batch; check that every glyph has the same visual weight.
4. OG and social templates last, using the approved mark and palette.

Higgsfield routes: Ideogram Vector 1.0 (SVG logos, icons and illustrations, or image-to-vector), Recraft V4.1 in vector mode, Ideogram 4.5 for transparent backgrounds and text replacement; Higgsfield's Brandkit skill builds palettes, editable SVG marks, mockups and brandbooks. Check `../higgsfield-notes.md`.

## Keeper checks (examples)

- The mark reads at 16 px and in one color
- Every icon in the set shares stroke, corner and weight
- Nothing resembles another brand's mark

## Typical spend

Stills and vectors: cheap. The cost is in iteration; cap concept boards at three rounds and decide.
